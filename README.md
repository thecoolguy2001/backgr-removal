# UNBG

> Cut out any background, on your machine.

Remove the background from any photo — free, unlimited, and **100% on-device**. The AI segmentation model runs in your browser via WebGPU; your image is never uploaded anywhere. Download the result as a transparent PNG.

**Run:** open `index.html` in a WebGPU-capable browser (recent Chrome/Edge) and drop in an image. The model (~45 MB) downloads once on first use, then it's cached and offline.
**Built with:** transformers.js (briaai/RMBG-1.4), WebGPU.
